# Інструкція з використання

Усі команди нижче запускайте з кореня репозиторію — каталогу, у якому
розташований `Cargo.toml`.

## 1. Повна ініціалізація через агента у VS Code

1. Відкрийте репозиторій у VS Code і перейдіть до **Copilot Chat**.
2. Увімкніть режим **Agent** у перемикачі режимів чату.
3. У меню вибору агента виберіть **Build Engineer**.
4. У полі чату введіть команду prompt `/init` і надішліть її.

Команда `/init` послідовно запускає `git-init`, `create-project`,
`create-build`, `create-actions` і `check`. Агент має повідомити статус кожного
етапу та зупинитися на першій помилці.

## 2. Окремий запуск команд проєкту

У Copilot Chat виберіть режим **Agent** і агента **Build Engineer**. Потім
виконуйте команди по одній, у наведеному порядку, надсилаючи кожну окремим
повідомленням:

1. `/git-init` — перевірити Git і правила `.gitignore`.
2. `/create-project` — створити або перевірити початковий Cargo-проєкт.
3. `/create-build` — налаштувати складання, тест `BasicAddition` і локальні
   CI-скрипти.
4. `/create-actions` — створити або перевірити GitHub Actions workflow.
5. `/check` — перевірити проєкт без виправлення вихідних файлів.

Переходьте до наступної команди лише після успішного завершення попередньої.
`create-project` залежить від `git-init`, `create-build` — від наявного
Cargo-проєкту, а `create-actions` — від скриптів `ci.sh` і `ci.bat`.

## 3. Локальна перевірка

Установіть Rust із Cargo та виконуйте команди в терміналі з кореня
репозиторію.

Збірка release-версії:

```sh
cargo build --release
```

Запуск тестів:

```sh
cargo test
```

Запуск CI-скрипту на Linux або macOS (у Bash):

```sh
bash ci.sh
```

Запуск CI-скрипту на Windows (у командному рядку `cmd.exe`):

```bat
ci.bat
```

У PowerShell запустіть Windows-скрипт так:

```powershell
.\ci.bat
```

Скрипти виконують release-збірку й тести та перевіряють наявність
виконуваного файла для відповідної платформи.

## 4. Запуск зібраної програми

Спочатку зберіть проєкт командою `cargo build --release` або запустіть
відповідний CI-скрипт. Виконуваний файл розміщується в `build/release/`.

На Linux і macOS:

```sh
./build/release/hello
```

У Windows PowerShell:

```powershell
.\build\release\hello.exe
```

У Windows `cmd.exe`:

```bat
build\release\hello.exe
```

Програма виводить:

```text
Hello, World!
```

## 5. Результати GitHub Actions

У GitHub відкрийте репозиторій і перейдіть на вкладку **Actions**. Виберіть
запуск workflow **Rust CI**, щоб переглянути його загальний результат і статус
окремих завдань для `ubuntu-latest`, `windows-latest` та `macos-latest`.
Відкрийте завдання для перегляду журналу його кроків.

Після успішного запуску завантажені виконувані файли доступні в розділі
**Artifacts** на сторінці цього запуску. Workflow запускається для подій
`push` і `pull_request` до гілок `develop` та `main`.
